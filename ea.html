67Labs Exit Manager

裁量トレーダーのためのポジション管理EA。
建値移動、自動決済、ワンクリック決済で、日々のトレードをサポートします。

無料ダウンロード 最新バージョン: v1.0 (MT5版)

FEATURES

⚡

手動エントリー＆自動決済

目標利益に達したタイミングでEAが自動決済します。

🛡️

指定利益での自動BE移動

あらかじめ設定した利益幅に到達すると、ストップロス（SL）を自動で建値（BE）へ移動。含み益をしっかり守り、利益を確保しながらポジションを管理します。

🔘

ワンクリック全決済

条件別クローズ操作をワンクリックで即座に行えます。

✂️

柔軟なハーフクローズ設定

部分決済（ハーフクローズ）を実行する際、どのポジションから優先して閉じるか（古い順・利益順など）を柔軟に設定できます。

🎛️

パネル移動＆最小化対応

チャート上の操作パネルはドラッグ＆ドロップで好きな位置へ移動可能。使わない時は邪魔にならないようコンパクトに最小化できます。

🎨

直感的なライン調整＆テーマ切替

SL・BE・TPなどの各種ラインをドラッグ操作で調整可能。チャートの背景に合わせて見た目を選べるテーマ切替（Sakura / Sky）も搭載。

HOW TO INSTALL

01

ダウンロード

上のダウンロードボタンからZIPファイルを取得し解凍します。

02

フォルダを開く

MT5の「ファイル」＞「データフォルダを開く」から「MQL5」＞「Experts」へ。

03

チャートごとに適用

監視・自動決済したい通貨ペアのチャートをそれぞれ開き、各チャートへEAを適用します。

04

アルゴリズム取引ON

MT5上部の「アルゴリズム取引」ボタンを有効にすればセットアップ完了です。
